CareerPilot – AI-Based Placement Preparation Platform
Overview

CareerPilot is a full-stack web application designed to help students manage and improve their placement preparation journey from a single platform.

While preparing for placements, students often use multiple websites for resume checking, GitHub analysis, job tracking, and career guidance. CareerPilot brings these important tools together into one centralized dashboard, making the process more organized and efficient.

The platform allows users to analyze ATS resume scores, track job applications, gain insights from their GitHub profiles, and receive AI-powered career recommendations.

Problem Statement

Students frequently struggle with:

Tracking multiple job applications
Understanding resume ATS compatibility
Analyzing their GitHub profile strengths
Identifying skill gaps for desired roles
Managing placement preparation efficiently

CareerPilot was built to solve these challenges through a single integrated platform.
